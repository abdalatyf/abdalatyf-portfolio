Automated Clinical Data Cleaning & Validation Engine

Automated Clinic Supply & Inventory ETL Pipeline

Python MySQL argparse logging
Problem

A multi-clinic network spent 3+ hours daily manually reconciling spreadsheets and syncing supply records, causing restocking delays and inventory stockout risks.

Action

Architected a CLI-driven ETL pipeline with --dry-run simulation, RotatingFileHandler logging, and idempotent MySQL loading using executemany() bulk inserts for zero duplicate ingestion.

3 hours → 5 seconds 5,000+ records/run 100% crash-resilient
